## 已集成的功能

### ✅ 1. 欢迎向导 (Welcome Wizard)

**功能位置**: 首次启动时自动显示

**测试步骤**:
1. 删除配置文件夹: `%USERPROFILE%\.mousemacros\config.json`
2. 启动 MouseMacros
3. 应该会自动弹出欢迎向导对话框

**预期结果**:
- 显示4页交互式向导
- 页面1: 欢迎和介绍
- 页面2: 基本操作说明
- 页面3: 快捷键设置指导
- 页面4: 开始使用提示
- "上一步"/"下一步"/"完成"按钮正常工作
- 勾选"不再显示"后，下次启动不会显示

**截图位置**: `docs/screenshots/welcome-wizard-*.png`

---

### ✅ 2. 热键验证警告 (Hotkey Validation)

**功能位置**: 设置 > 自定义热键

**测试步骤**:
1. 启动 MouseMacros
2. 点击"设置"按钮
3. 点击"自定义热键"
4. 点击任意输入框
5. 按下以下按键并观察警告:
   - 音量增大/减小键 → 应显示媒体键警告
   - F13-F24 → 应显示Fn键提示
   - 正常按键(F1-F12, A-Z) → 无警告

**预期结果**:
- 按下问题键时弹出警告对话框
- 警告内容为中文（如果语言设为中文）
- 警告包含:
  - 为什么该键可能无法录制
  - 推荐使用的替代按键

**截图位置**: `docs/screenshots/hotkey-validation-*.png`

## 如何运行测试版本

### 方法1: 直接运行JAR
```bash
java -jar target/MouseMacros.jar
```

### 方法2: 从源码构建并运行
```bash
mvn clean package -DskipTests
java -jar mousemacros-app/target/MouseMacros.jar
```

### 方法3: 在IDE中运行
1. 在IDE中打开项目
2. 运行 `mousemacros-app/src/main/java/.../Main.java`
