
## 🎨 布局技术细节

### 布局结构
```java
JPanel container (BoxLayout.Y_AXIS)
├── JPanel row1 (FlowLayout.LEFT, 10, 5)
│   ├── hotkeyBtn
│   └── wizardBtn
├── JPanel row2 (FlowLayout.LEFT, 10, 5)
│   ├── aboutBtn
│   ├── updateInfoBtn
│   └── exportLogBtn
└── JPanel row3 (FlowLayout.LEFT, 10, 5)
    └── scriptBtn
```

### 间距设置
- **水平间距**: 10px（按钮之间）
- **垂直间距**: 5px（行间距）
- **对齐方式**: 左对齐 (LEFT_ALIGNMENT)

### 为什么使用BoxLayout + FlowLayout组合？
- **BoxLayout**: 垂直排列，每行高度自动
- **FlowLayout**: 每行内水平排列，间距一致
- **优势**: 响应式布局，窗口大小改变时自动调整

## 💡 设计原则总结

1. **频率优先**: 高频功能放在上方
2. **视觉分组**: 相关功能聚集在一起
3. **一致间距**: 统一的10px水平间距
4. **响应式布局**: 适应不同窗口大小
5. **语义清晰**: 通过位置传达功能重要性
